# Preview image of a template

The Properties tab of a section template carries a **Preview image** field, uploaded with the icon in the field. It is
meant to make the editors' work easier in ContentCreator and SiteArchitect: a meaningful screenshot that shows how the
template looks in the frontend or what it does, or another graphic that shows how to apply it correctly. `[odfs]`
FirstSpirit 2026.11, *Properties tab* of the section template; the *Properties tab* pages of the page template and of
the table template carry the same field with the same text `[odfs]` 2026.5. Its purpose is to support the editor in
choosing the right template, so it appears where templates are chosen (the pages name no dialog). Template exports of
the reference projects hold `PreviewImage.png` in the folders of page, section and table templates `[observed]`
2026-10-30.

It is a different setting from the snippet (`snippets.md`), which describes each object by its content. Whether the
image can be set over REST has not been checked `[verify]`. Design guidance is in the `firstspirit-template-design` skill
(its `preview-image.md`).
