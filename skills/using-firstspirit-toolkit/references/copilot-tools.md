# GitHub Copilot Tool Mappings

When a skill mentions these abstract operations, use the corresponding GitHub Copilot tool:

| Abstract operation | GitHub Copilot tool |
|--------------------|---------------------|
| Read a file | `read` |
| Edit a file | `edit` |
| Search file contents | `grep` |
| Match file paths | `glob` |
| Run a shell command | `run_command` |
| Search the web | `web_search` |
